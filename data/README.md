# Data

`iris.data` and `iris.names` are the classic Iris files from the UCI Machine
Learning Repository (https://archive.ics.uci.edu/dataset/53/iris), created by
R. A. Fisher (1936) and donated by Michael Marshall. They are small (about 4.5 KB)
and are kept in this repository so the notebooks run offline.

Please check the dataset page above for the current license and citation
terms before you reuse the data.

Known detail: `iris.names` says samples 35 and 38 in the UCI file differ from
Fisher's paper. This repository keeps the file exactly as downloaded.
